## Типові «питання із зали»

- **«Чому на Floci cold start такий довгий?»** — це запуск Docker-контейнера, а не Firecracker; змінюється відносна різниця.
- **«А provisioned concurrency?»** — у Floci не реалізовано; показуємо лише на слайді 16.
- **«Чому `provided.al2023`, а не `go1.x`?»** — `go1.x` знято; Go — кастомне середовище (слайд 15).
- **«Чому бінарник називається `bootstrap`?»** — цього вимагає OS-only runtime.
